HOW TO USE
1. Unzip and open index.html in a browser.
2. Edit js/config.js to change name, text, skills, projects, links, social links.
3. Images: put your photos in the images/ folder (jpg/png/webp) and change the
   paths inside js/config.js (hero, about, project images).
4. Colors: css/style.css -> :root variables at the top.
